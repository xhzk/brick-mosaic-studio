# 乐高像素画 MOC 工坊

把照片转换成可以用积木拼搭的像素画。你可以裁剪和调色，选择采购配色或现有套装，再按最终效果生成用料清单和分区拼搭 PDF。图片处理在浏览器中完成。

感谢 Deb 开源，本项目在其基础上开发。

## 本地启动

用 VS Code 打开项目，在 `app/index.html` 上选择 **Open with Live Server**（需要插件 Live Server）。如果已安装 Python，也可以在项目根目录运行：

```sh
python -m http.server 8000 --directory app
```

然后打开 [http://localhost:8000](http://localhost:8000)。

## 制作像素画

1. **选画面**：上传照片，拖动裁剪框确定构图，设置横竖颗粒数量。
2. **调照片**：选择调色预设，或展开「手动微调」调整色相、饱和度、亮度和对比度。
3. **选积木配色**：默认使用 46 色采购配色，也可切换到含商家色号的 56 色配色或现有套装。在「画面效果」中选择清晰色块、柔和渐变或颗粒质感，也可以用画笔局部改色。做套内改搭时，选择对应套装并使用有限库存模式。
4. **拿图纸**：查看实时效果和用料清单，点击「生成彩色拼搭图纸」下载 PDF。按首页的分区编号逐块拼搭。

做立体像素画时，从第一步打开「立体制作」，自动生成或上传深度图，再设置层数和深度阈值。预览满意后，分别导出垫片图纸和彩色图纸，前者用于堆出高度，后者用于铺设表面颜色。
